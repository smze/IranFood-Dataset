
# IranFood Dataset — Pilot Experiment

## Overview

An initial pilot experiment was conducted to evaluate the IranFood dataset for Iranian food image classification.

The pilot dataset included:

* **1,903 images**
* **18 food classes**
* **3 CNN architectures:** ResNet, MobileNet, EfficientNetB0

## Initial Results

| Model              | Validation Accuracy | Validation F1 |
| ------------------ | ------------------: | ------------: |
| ResNet             |              62.48% |        62.01% |
| MobileNet          |              79.29% |        79.11% |
| **EfficientNetB0** |          **81.95%** |    **81.86%** |

These results represent an **initial baseline on the pilot dataset** and are not the final performance of the expanded dataset.

## Current Direction

The dataset is currently being expanded to increase:

* Number of food classes
* Image diversity
* Data quality
* Real-world applicability

Further experiments will evaluate model performance as the dataset grows.
