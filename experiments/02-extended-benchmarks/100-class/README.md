# 100-Class Dataset — Development Status

## 1. Overview

The 100-class version is the next expansion stage of the Iranian food image dataset.

It is being prepared to increase food-category coverage and support future food recognition and nutrition-related AI applications.

## 2. Current Status

Current development activities include:

- Dataset cleaning and quality control
- Image validation and consistency checks
- Class organization and label review
- Preparation of training, validation, and test CSV files
- Dataset version consistency checks

## 3. Planned Benchmarking

The extended benchmarking framework used for the 18-class and 42-class versions is planned to be applied to the 100-class dataset.

The planned evaluation includes:

- EfficientNet-B0
- ResNet18
- MobileNetV2
- Vision Transformer (ViT-B/16)
- GPU-based training
- Classification metrics
- Confusion matrix analysis

## 4. Development Status

**Status:** In progress — dataset cleaning and preparation.

Benchmark results will be added after the dataset version is finalized and the experiments are completed.
